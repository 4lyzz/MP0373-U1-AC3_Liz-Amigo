1. Per a què serveix <form>? Recull dades de l'usuari i les envia al servidor.
2. Per a què serveix action? Indica la URL on s'envien les dades del formulari.
3. Per a què serveix method="get"? Envia les dades a través de la URL de manera visible.
4. Per a què serveix name? Identifica el camp de dades quan arriba al servidor.
5. Quina diferència hi ha entre id i name? L'id és únic per a CSS i QLabel; el name s'utilitza per processar les dades al servidor.
6. Per a què serveix value? Defineix el valor predeterminat o enviat d'un element.
7. Per què els radio d'un mateix grup tenen el mateix name? Perquè siguin excloents entre si i només es pugui triar una opció.
8. Per què els checkbox d'aficions utilitzen [] al name? Per agrupar-los en un array a PHP i rebre múltiples seleccions.
9. Quina diferència hi ha entre select i datalist? El <select> tanca les opcions a triar; el <datalist> permet suggeriments i escriure lliurement.
10. Per a què serveix required? Obliga a omplir el camp abans d'enviar el formulari.
11. On trobem les dades normals enviades per GET en PHP? A la variable superglobal $_GET.
12. On trobem la informació dels fitxers pujats? A la variable superglobal $_FILES.
13. Per què no necessitem JavaScript en aquesta pràctica? Perquè HTML valida i gestiona el formulari de forma nativa.
